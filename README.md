Most of these scripts are created by or with AI.

# Usage (WIP)

## `AutoVPK.ps1`
Creates a ready-to-use `pak01_dir.vpk` from a mod folder using VPKEdit CLI. It can open a Windows folder picker, remember the last destination, delete old `pak01*.vpk` files, and package the contents of the local `pak01` source folder into the target mod directory.

## `CVARLIST Format Tool.ps1`
Converts Source Engine `CVARLIST` CSV exports into organized `.cfg` files. It supports interactive configuration for output naming, command type filtering, flag handling, and grouped sections, making large cvar/concommand dumps much easier to read and use in-game.

## `NealFun Stimulation Script.js`
A browser automation/userscript for the NealFun “Stimulation” game. It adds a floating control panel to automate clicks, minigames, upgrades, stock trading, inbox actions, and audio muting so the game can be played with less manual input.

## `SAR Dump Format Tool.ps1`
Formats SAR JSON dump data into clean `.cfg` files in a similar style to the CVARLIST tool, but tailored for Source Engine SAR plugin command dumps. It can filter Game vs SAR entries, tag SAR commands, handle flags, and split output into organized sections for easier use.
